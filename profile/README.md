## One hosted connection for your advertising work

[getmcpads](https://www.getmcpads.com) connects **16 advertising, measurement, analytics and search sources** to compatible AI assistants through a hosted MCP connection. Media buyers, marketers and agencies can move from a performance question to a creative review, a spreadsheet report or a proposed campaign change in the same conversation.

| What you need to do | How getmcpads helps |
| --- | --- |
| Understand performance | Investigate acquisition costs, compare campaigns and prepare reports across connected accounts. |
| Review creatives | Explore a creative gallery and visual comparisons alongside performance data. |
| Retrieve media | Retrieve supported ad images and videos for inspection and reuse. |
| Keep Google Sheets current | Export supported reports to Google Sheets and schedule automatic refreshes. |
| Prepare ads in bulk | Combine a brief with media from Google Drive, Dropbox or supported conversation attachments to prepare batches of ads. |
| Make campaign changes | Preview supported budget, status, targeting and campaign changes before confirming them. |
| Work across clients | Organize workspaces, select accessible accounts and prepare client reviews. |
| Connect advertising to analytics | Bring GA4, Search Console and Adjust into acquisition, search and app performance analysis. |

**The 16 sources:** Meta Ads, Google Ads, TikTok Ads, Pinterest Ads, X Ads, Snapchat Ads, Amazon Ads, Apple Ads, Microsoft Advertising, Reddit Ads, LinkedIn Ads, ChatGPT Ads, RTB House, Adjust, Google Analytics 4 and Google Search Console.

Capabilities vary by source, account permissions, plan and AI client. See the [source documentation](https://www.getmcpads.com/tools) and [current plans](https://www.getmcpads.com/pricing) for availability. The demo uses staged data.

Each repository includes setup instructions, tool schemas, a changelog, versioned releases and CI on Node 22, 24 and 26. Requires **Node.js 22.23.4, 24.22.1, 26.12.1 or a newer release of those lines**, which carry the October 2026 security fixes, and a compatible stdio MCP client.

```bash
npx -y @getmcpads/meta-ads-mcp-server
```

Advertising write tools are disabled by default. When enabled, they preview a change before a call with explicit confirmation applies it, and new campaigns start paused or as drafts. GA4, Search Console and Adjust are read-only.

The hosted product adds its own interface and workflows, including creative galleries, scheduled exports, cloud media imports and shared workspaces. These are separate from the standalone packages listed above.
